# LabGit-Settings
## Назначение проекта
Учебный проект для демонстрации настройки системы контроля версий GitHub, работы с фильтрами и структурой каталогов.

## Структура каталогов
- `src/` — исходный код проекта (C#).
- `docs/` — документация и описания.
- `tests/` — тестовые материалы.
- `assets/` — вспомогательные ресурсы.

## Исключаемые файлы (.gitignore)
Из отслеживания исключены: папки сборки (build, bin, obj), временные файлы, логи, локальные настройки (.env), файлы ОС и IDE.

## Настройки репозитория
Используется файл `.gitattributes` для нормализации окончаний строк (CRLF для кода, LF для документации) и определения бинарных файлов.
